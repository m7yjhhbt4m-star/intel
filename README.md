# Intel Research

A source-linked research library for investigations, technical evaluations, and handoffs between AI assistants.

## Research reports

- [Claude Code Software Factory — source verification, technical critique, and MacBook Pro/Docker proof-of-concept plan](research/software-factory-claude-code/RESEARCH_HANDOFF.md)

## Research standards

Each report should identify:
- who prepared it and when;
- primary sources and exact versions/commits checked;
- what was inspected versus what remains unverified;
- confirmed facts separately from risks, assumptions, and recommendations;
- actionable next steps and enough context for another AI assistant to continue without repeating the entire investigation.

This repository is public. Do not add secrets, private records, personal information, or research that should not be public.
