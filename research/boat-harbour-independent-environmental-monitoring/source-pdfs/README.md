# Original Boat Harbour Source PDFs

Upload original, unmodified PDF source documents for the Boat Harbour independent environmental monitoring research here.

## Handling
- Preserve original filenames and files unchanged.
- Do not upload duplicate copies where practical; duplicates can be identified during the later inventory and deduplication pass.
- Keep source PDFs in the appropriate subfolder when the category is clear:
  - `historical-records/`
  - `legal-agreements/`
  - `technical-reports/`
  - `scientific-and-community-research/`
- If unsure where a document belongs, upload it directly into `source-pdfs/` rather than guessing.

The research source register will track each document's provenance and review status. A file being uploaded does not mean it has been analysed or verified.
